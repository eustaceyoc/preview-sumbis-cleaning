# Sumbi's Cleaning (sample site)

A sample website I designed for Sumbi's Cleaning, a home and office cleaning business in Raleigh, NC. I put together sites like this to show local businesses what a modern, mobile-friendly web presence could look like for them before they commit to anything.

**Live preview:** https://preview-sumbis-cleaning.vercel.app

## Design

A bento-grid layout with DM Serif Display and Plus Jakarta Sans. Each tile covers one thing (services, service area, what to expect) so it's easy to scan on a phone.

## Stack

- Plain HTML and CSS in a single `index.html`, with no framework and no build step
- Responsive, mobile-first layout
- Google Fonts, plus photos from Unsplash (credited on the page)
- Hosted on Vercel

## Running it locally

Open `index.html` in a browser, or serve the folder with something like `npx serve .`

## Notes

- This is a sample site, not the business's official website, and it isn't affiliated with or published by Sumbi's Cleaning.
- The contact form is for demo purposes only and doesn't send anything.
- Search engines are blocked for now (`robots.txt` and a `noindex` header in `vercel.json`) until the business decides whether it wants the site live.
